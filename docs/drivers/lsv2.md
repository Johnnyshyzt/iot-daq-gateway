# 海德汉 LSV2

协议：TCP，默认端口 19000。帧为 4 字节大端载荷长度、4 字节 ASCII 命令、载荷。实现对照公开的 pyLSV2 描述。

登录先 `A_LG` 角色 `INSPECT`，再尝试 `DNC`（可带密码）。状态读取使用 `R_RI`：执行状态 23、选择程序 24、倍率 25、程序状态 26、第一条错误 27、刀具 51、轴位置 22。版本使用 `R_VR`。

能读到的目录项：状态、工作模式、是否运行、当前程序、主程序、行号、进给/主轴/快移倍率、报警与报警号、刀号、机械坐标、软件版本。

主轴转速和实际进给速度不在这组报文里，目录里标为不可用。

控制器需要打开 LSV2 / DNC，并允许所填密码。INSPECT 被拒绝时仍继续尝试 DNC。

验证状态：协议级或模拟器已核对，需在真实机床上做现场验收（verified on simulator/protocol level only, needs on-site acceptance on a real machine）。帧编解码有单元测试；没有连过真实 TNC。
