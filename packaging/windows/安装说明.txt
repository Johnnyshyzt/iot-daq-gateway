IoT 采集网关 — Windows x64 现场包
================================

本目录是自包含发布（win-x64 self-contained）。一个 Host.exe 同时提供页面、管理 API 和采集。
现场工控机不需要安装 .NET SDK，也不需要 git。
不要把 Linux Docker 当作生产 FOCAS 采集方式。

1. 解压到例如 C:\iot-daq-gateway\ （不要只拷 Host.exe，本目录全部文件都要保留）
2. 把授权的 Fwlib64.dll 放到本目录（与 Host.exe 并列）。仓库/镜像从不附带该库
3. 先双击 run-console.bat，浏览器打开 http://127.0.0.1:5080 ，用 admin / admin 登录
4. 在页面里配置设备和 MQTT，发布。采集读取 data\published
5. 确认后，右键 install-service.bat → 以管理员身份运行。开机后服务 IotDaqGateway 会自动启动
6. 卸载：右键 uninstall-service.bat → 以管理员身份运行（不会删除 data\ 下的配置、日志或 Fwlib64.dll）

包里的 gateway.focas.yaml 只是参考，服务不会自动加载它。
日志：本目录 logs\gateway-yyyyMMdd.log（保留约 14 天）。

验收：订阅 daq/# ，看设备 $status 变为 online，state 随机床变化（不是 Fake 的 60 秒相位）。
